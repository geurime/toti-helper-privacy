6. 개인정보의 파기

  • 개인정보 수집·이용 목적이 달성된 후에는 해당 정보를 지체 없이 파기합니다.
  • 회원 탈퇴 시 모든 개인정보(이메일, 비밀번호 해시, 보육일지, 학습 결과, 사용 기록)는 데이터베이스에서 즉시 삭제됩니다.
  • 회원은 확장프로그램 내 "전체 삭제" 기능을 통해 언제든 본인의 보육일지 데이터를 즉시 삭제할 수 있습니다.
  • 관련 법령에 의해 보존이 필요한 정보를 제외하고 즉시 파기합니다.

7. 이용자의 권리와 행사 방법

이용자는 언제든지 다음의 권리를 행사할 수 있습니다.

  • 개인정보 열람·정정·삭제·처리 정지 요구
  • 동의 철회 (회원 탈퇴)

권리 행사 방법

  • 일지 데이터 삭제: 확장프로그램의 "전체 삭제" 기능 사용
  • 회원 탈퇴 및 기타 요청: support@geurime.com 으로 문의

8. 개인정보의 안전성 확보 조치

  • 비밀번호 단방향 암호화: bcrypt(10 rounds)로 해시 처리하여 저장 (복호화 불가)
  • 통신 암호화: 모든 통신은 HTTPS(TLS)로 암호화
  • 인증 토큰 만료: JWT 토큰은 발급 후 30일 자동 만료
  • 세션 무효화: 비밀번호 변경 시 발급된 모든 토큰을 무효화하여 모든 기기에서 자동 로그아웃
  • API 호출 빈도 제한: 사용자별 분당 호출 횟수 제한(Rate Limit) 적용
  • API 키 보호: 외부 AI API 키 등 민감 정보는 서버 환경변수에만 보관하며, 클라이언트 코드에 포함되지 않습니다.
  • 접근 권한 최소화: 개인정보 처리 담당자를 최소화

9. 개인정보 유출 시 대응

개인정보 유출이 확인된 경우, 회사는 다음과 같이 대응합니다.

  1. 지체 없이 해당 이용자에게 유출된 항목, 유출 시점, 대응 조치를 통지합니다.
  2. 개인정보보호위원회 및 한국인터넷진흥원에 법령에 따라 신고합니다.
  3. 피해 최소화를 위한 기술적·관리적 조치를 즉시 시행합니다.

10. 만 14세 미만 미성년자의 개인정보

또띠헬퍼는 어린이집 보육교사를 대상으로 하는 서비스이며, 회사는 만 14세 미만 미성년자의 회원가입을 원칙적으로 제한합니다.

회원이 보육일지를 작성하는 과정에서 아동의 정보(예: 활동 기록 내 이름)가 포함될 수 있으나, 이는 회원이 보육 현장에서 작성하는 업무 기록의 일부이며 회사는 해당 정보를 별도로 식별·관리하거나 마케팅 목적으로 이용하지 않습니다. 회원은 일지 작성 시 아동의 개인정보 보호에 유의해야 하며, 이에 대한 책임은 회원 본인에게 있습니다.

11. 외부 사이트와의 관계

또띠헬퍼는 한그루(hangloo.co.kr) 사이트에서 동작하는 크롬 확장프로그램입니다. 회사는 한그루의 운영 주체와 무관한 독립적인 서비스 제공자이며, 한그루 사이트 자체의 개인정보 처리에 관한 사항은 해당 사이트의 개인정보처리방침을 따릅니다. 또띠헬퍼는 한그루 페이지의 입력 영역(textarea) 내용에만 접근하며, 그 외 한그루 사이트의 개인정보(예: 한그루 로그인 정보, 어린이집 관리 데이터)에는 접근하지 않습니다.
